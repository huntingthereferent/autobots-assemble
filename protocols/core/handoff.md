# Core Protocol — Handoff

A handoff moves execution to another AI, tool, repository, person, or future session without changing what the work means.

## Required handoff state

- current referent
- goal / acceptance condition
- current result state
- evidence used
- unresolved witnesses / walls
- artifacts and exact locations
- next movement
- claims that must **not** be upgraded

## Closure requirement

The receiver must be able to continue using the same witness/evidence contract. If the receiving layer requires a different contract, record an explicit protocol boundary before transfer.
