# Work Protocol — External Bounded Problem

## Referent

The external specification as supplied.

## Order

1. external specification
2. definition of solved / acceptance condition
3. required inputs and available evidence
4. current implementation attempt
5. test/acceptance evidence
6. submission state
7. payment/result state
8. older experiments

## Witness contract

Do not claim completion unless the published or client-supplied acceptance condition has been tested. If a private file, environment, credential, or hidden test is required, mark the work \`PARTIAL\`/\`WALL\` and name the dependency.

## Continuation

The result becomes evidence for the next pass: submit, adapt, retest, or archive.
