# Protocol — Language Render

## Referent

A supported movement/state that needs a human-language surface.

## Input

Shape/state + referent + target language/register + optional pragmatic constraints.

## Witness contract

The selected wording must preserve the underlying movement and may not silently strengthen certainty, authority, approval, urgency, or scope.

## Output

A surface expression plus the language/register metadata used to produce it.

Rendering creates no network movement.
