## Characterized mechanic

The public game table describes WA30 as:

> Sokoban variant: push boxes onto goals while autonomous helper/antagonist bots act each step.

So unlike static Sokoban, every player action may also advance other actors.

## Failure boundary

WA30 appears in the deep-wall/procedure-wall set where large search budgets reached many states without reliably causing the actual level-up.

The difficult part is not just:

```text
find a path for the box
```

It is:

```text
choose an action
→ player/box consequence
→ autonomous actors also update
→ new tactical state
→ preserve future solvability
```

A static board-distance heuristic can therefore improve while the real plan becomes worse.

## Direct lesson

WA30 adds a fourth hard-case requirement:

```text
correct current-state geometry
≠
correct future trajectory
```

The solver has to reason over the **transition**, including autonomous responses, not just score the resulting board by closeness to targets.

This makes WA30 a concrete test of whether a future first-contact solver can distinguish:

- controllable effects;
- autonomous effects;
- favorable autonomous help;
- adversarial/interfering autonomous motion;
- irreversible box placements.
