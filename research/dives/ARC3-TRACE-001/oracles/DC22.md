## The critical failed-model episode

Before the later full solve, a source-free EWM investigation of a deep DC22 wall reported a highly rigorous negative result.

Its learned model included:

- a 2x2 player in a bounded pocket;
- an apparently separated goal;
- eight panel-button effects;
- portal behavior;
- incremental bridge/slide effects.

It then performed:

- a maximally permissive reachable-cell over-approximation;
- a complete pocket state graph;
- hundreds of toggle-configuration sequences;
- alternate prior-level exits to test spawn carryover.

Within that model, the goal was concluded geometrically unreachable.

Yet later audit-clean source-free Fable runs reached **6/6**.

## Direct lesson

This is the strongest caution so far:

```text
exhaustive proof inside current model
≠
proof about the real game
```

The proof can be internally valid while the model is missing a transition, interaction, representation, or ordered procedure.

So when the real benchmark says the level is solvable but the current model proves "impossible", the correct status is:

```text
MODEL INCOMPLETE
```

not:

```text
GAME IMPOSSIBLE
```

unless the model's completeness has itself been externally established.
