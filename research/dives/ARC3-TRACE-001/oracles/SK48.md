## Failure boundary

Earlier attempts were explicitly described as plateauing and likely tunneling on one framing.

A topology/reachability lens was proposed as an alternate framing, but the actual task description shows why one lens can be insufficient:

```text
spatially reachable
≠
sequence-correct
```

and:

```text
sequence target understood
≠
physically realizable push plan
```

Both must hold simultaneously.

## Direct lesson

SK48 adds a dual-representation requirement:

```text
plan in geometry
AND
evaluate in sequence space
```

A solver that collapses the game into only one representation may make locally valid progress while destroying the other constraint.

The practical question is not "which representation is correct?"

It is:

```text
which independent constraints must remain true together?
```
