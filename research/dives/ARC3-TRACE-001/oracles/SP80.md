## Failure boundary

Early search could reach the first level, but full chaining remained difficult.

The important structural fact is:

```text
same/similar visible board
+ different interaction history
→ potentially different win readiness
```

If an agent treats the current image as a complete Markov state, it can merge states that are task-distinct.

## Direct lesson

SP80 adds a history-state failure class:

```text
current pixels
≠
complete causal state
```

The solver may need to preserve latent history variables inferred from interaction:

- number/pattern of ACTION5 uses;
- order of earlier moves/interactions;
- accumulated trigger state;
- phase/progress not directly rendered.

This does not justify inventing arbitrary hidden variables.

A hidden history variable is earned when:

```text
visually equivalent states
+ same next action
→ different observed consequence
```

or when repeated evidence shows reward depends on an earlier sequence.
