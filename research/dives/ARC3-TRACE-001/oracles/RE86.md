## Direct lesson

RE86 removes a tempting explanation for BP35/LF52 difficulty:

```text
hardness ≠ coordinate-click combinatorics
```

A purely directional/action-5 game can still require a deep, specific procedure that ordinary state-progress heuristics fail to capture.

So we now have three distinct hard-case signals:

1. BP35 — locally strong mechanic model can still miss the procedure.
2. LF52 — correct model can still need deep offline search.
3. RE86 — even a useful progress/subgoal gradient can still fail to identify the exact reward-producing procedure.

## Solve-the-Whole-Thing implication

During live first-contact solving, do not let a monotonically improving proxy silently become the goal.

Require:

```text
proxy progress
→ candidate route
→ actual level-up witness
```

If repeated proxy improvement produces no level-up, switch from "go farther" to:

```text
what exact ordered event/procedure has not happened yet?
```
