# Research Dives

This is the durable shelf for random academic/technical rabbit holes.

The point is **reviewability**, not publication polish.

## Folder shape

Each saved dive gets a folder like:

```text
research/dives/
└── DIVE-0001_short-slug/
    ├── dive.json      # canonical state
    ├── DIVE.md        # human-readable output lens
    ├── notes/         # optional working notes
    ├── sources/       # optional source extracts/metadata
    └── artifacts/     # optional figures/code/results
```

The root [`INDEX.md`](INDEX.md) is the browseable shelf. `index.json` is the machine-readable registry.

## What is worth saving?

Save it if future-you might reasonably say:

- “what was that weird thing we found?”
- “I want to go back down that branch.”
- “didn’t this connect to something else?”
- “which paper/result was that?”
- “I want to compare this to a later dive.”

A dive can be one page or fifty. It does not need to become a formal research project.

## Status

- `seed` — captured but barely explored
- `active` — currently being explored
- `paused` — intentionally parked for later
- `closed` — the present dive has a sufficient stopping point

Closed does not mean “truth completed”; it only closes that exploration path.
