# ML / OpenML Iris v1 — source-specific held-out test

**Source:** [OpenML dataset 61, version 1](https://www.openml.org/d/61), `iris`, source publisher/UCI iris archive; metadata originally observed in [run 39771470448](https://github.com/huntingthereferent/autobots-assemble/actions/runs/39771470448), from exact URL `https://www.openml.org/api/v1/json/data/61`, with metadata SHA-256 `7e408fec68984cfcf25f360ca267e706bc5ef27284a17351f78429660c14acd0`. Upstream public OpenML dataset listing identifies **version 1**, **150 records**, **3 classes**, **4 numeric input measurements**, class target `class`. OpenML lists it as **Public**. Each new measurement records exact current response hashes, downloaded ARFF SHA-256, declared-source MD5 match if available, and retrieval UTC. Metadata can change; the original first-pass hash remains an independently dated witness.

**Frozen question:** On this one data version and one predeclared 30/120 holdout split, does a train-only standardized nearest-centroid classifier exceed the train-set majority-class baseline? **This is not a reproduction of Fisher's 1936 study**, nor evidence of generalization to new species, data sources, or algorithms. No published effect size is assumed proven.

**Split contract:** Group identical feature vectors so a duplicated physical row cannot appear in both training and test; use SHA-256 seeded, stratified group selection to retain 10 held-out examples per class, 120 training / 30 testing. Fit all scales and centroids only on training rows. Compare numeric accuracy on the exact same held-out rows with a majority-class baseline; tie-breaking is deterministic and class counts are preserved. The source must have exactly 150 rows, 4 finite numeric features and 3 balanced classes. Any conflicting duplicate-feature labels, missing values or unexpected schema become `SOURCE_WALL` rather than silently changing the experiment.

**Rights/data:** No source ARFF or participant data committed or redistributed. Public biological benchmark metadata is not a license for unrelated redistribution; OpenML's dataset/public terms must govern use.

**Run:** Offline 13 synthetic controls under `python -m unittest discover -s research/studies/ml_openml_iris_v1 -p 'test_*.py' -v`. Default CLI is `UNOBSERVED`; `python research/studies/ml_openml_iris_v1/experiment.py --live --output openml-iris-derived.json` requests only two exact OpenML endpoints, checks identity and hashes, and writes **derived-only** metrics. Network source walls are explicit, not reported as scientific findings.

**Boundaries:** One snapshot; no alternate split/seed repetitions, uncertainty intervals, class-subgroup confidence statements, leakage beyond exact duplicates assessment or controlled changes in dataset version. The broader 21-lane registry remains unchanged; this study is a distinct, scoped witness in **ML** alone.
