## 5. The result for the proposed fractal game loop

Native A/B can compress 243 source histories into one present
public state while retaining distinct ways that state arose.
We can re-expand that category to create a spatially branching
world without losing the source of each branch.

But branch multiplicity alone does not create 243 different native
outcomes. To make it an actually branching game, each projected
subspace needs an earned or declared interaction/constraint that can
distinguish some futures. The next A/B layer must test those
differences; where no witnessed difference exists, branches remain
alternative source addresses of the SAME category. A later
counterexample must split the category, never silently overwrite it.
