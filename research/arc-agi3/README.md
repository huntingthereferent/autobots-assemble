## Reproducibility limits

Historical ARC scripts contain machine-specific absolute Windows paths. They require a compatible ARC SDK and possibly original environmental assets. This archive is not a drop-in runnable toolkit.

Excluded: venv dependencies, downloaded third-party game/environment implementations, Python bytecode, pickle object dumps, and vendor downloads. Those are not user-authored research source.

Inversion of A/B source categories has finite-horizon native evidence. The fractal spatial maps are a chosen mathematical model, not a proven native SK48 rule. The proposed construction adapter is a local tested prototype, not production agent integration.
