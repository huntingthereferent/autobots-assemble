**Research date:** October 17, 2026, America/Chicago (runs logged in UTC October 18). This uses the repository's ORIGINAL 48-law F3 WindowCombined source, not the historical nine-law experiment.

## Native mathematical preflight — two-control composites

- [Official native run #39098166017](https://github.com/huntingthereferent/autobots-assemble/actions/runs/39098166017); [raw native frames and complete JSON](https://github.com/huntingthereferent/autobots-assemble/actions/runs/39098166017/artifacts/12125870650).
- [Reproducible exact-native macro screen](../native_window48_composite_probe.py).

Every original mathematical Window48 law requires A cubed to be identity, with a strict period-three orbit at the marked origin. The experiment did NOT assign native action IDs to mathematical letters. Instead it tested every ordered pair of DISTINCT root-advertised simple actions among ACTION1 through ACTION5 in all 25 official public ARC games, under an explicitly provisional interpretation as a single composite candidate W. W, W² and W³ were observed on fresh native resets.

Observable state factors were fixed before running: exact complete original 64x64 native frames and all 16 exact binary per-native-color 64x64 masks. No pixels or colors were reduced modulo 3. Any strict three-cycle discovery would require fresh native six-cycle replication and a second starting context. Even then it would not establish a native mathematical state mapping or hidden-state identity.

There were 4,112 individual exact color-mask comparisons (257 completed paths times 16 native colors); none exhibited a strict three-state orbit. A constant mask returning to itself is NOT a mathematical generator witness. No color candidate met the replication threshold, so no candidate was promoted.

**Scope:** The negative result concerns ordered macros of exactly two *distinct* native simple controls at those public game roots, using complete frames and individual exact-color masks only. It does not refute the original 48 F3 laws, longer or parameterized native actions, hidden states, or any independently justified alternative observable factor.

## Independent native SP80 level advancement

The macro screen interrupted one SP80 trajectory on a native level-count change under repeated ordered controls 4 then 5. This was recorded as an incomplete mathematical A-cube trial, not assumed to be a valid F3 cycle or a full ARC game win.

- [Independent actual native SP80 verification run #39098490947](https://github.com/huntingthereferent/autobots-assemble/actions/runs/39098490947).
- [Raw real native frames and level-count action log](https://github.com/huntingthereferent/autobots-assemble/actions/runs/39098490947/artifacts/12125219208).
- [Executable witness](../native_sp80_level_recheck.py) and [CI workflow](../../../.github/workflows/arc3-native-sp80-recheck.yml).

Before this verification, the following word trials were fixed: 4, 5, 45, 54, 44, 55, 4545, 5454, 454545, 545454, 444444, 555555. Each word was independently tried from **two fresh native resets**, 24 resets and **84 real native actions** in total. The starting exact full-frame hash was the same in all 24 resets.

Only **454545** produced observed game-level progress in this bounded comparison. In **both independent resets**, the native levels_completed counter rose **0 to 1** on action 6, and the actual SDK state was **GameState.NOT_FINISHED**. Reversed and shorter sequences had no such progress in their tests.

The first independent replay script mishandled animation stacks returned by some native actions, so its initial workflow was NOT scientifically classified. The corrected passing run selects the last 64x64 image while separately recording the SDK's native state and levels_completed **before** pixel decoding. An action-5-only sequence still yielded a nonstandard native frame in two trials; this unresolved input does not justify universal claims about its behavior.

**This is authentic native public-game LEVEL progression, not a complete game win.** It is also NOT source-defined F3 A: the three repetitions of the two-action word changed the native game level instead of returning the complete state to its start. It does not establish A/B roles, F3 conjugacy, a class of the 48 mathematical worlds, or a general policy for solving other ARC games. No saved winning routes or game source were consulted.
