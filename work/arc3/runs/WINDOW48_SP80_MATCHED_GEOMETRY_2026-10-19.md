## Interpretation

The combined verified evidence is:
- Same *one* pre-action native interior under different recorded histories and row63 states: 42/42 ACTION5 returned **22** in preceding independent native experiment.
- Different source-selected pre-action interiors with the exact same movement suffix, action count and native boundary state: ACTION5 can return **22/23/26/28** frames; all four patterns independently reproduced.
- Original ACTION5 length is therefore neither universally 22, nor explained solely by earlier ACTION5 use or native action age. The result is consistent with **observable pre-action interior configuration influencing animation response in these source conditions**. It does NOT identify a full source game physics mechanism or prove that exact native pixels universally determine returned frame count.
- **Every original SDK trial remained native level1/6**, so correct temporal prediction is not a game solve, an original ARC competition win, or proof of F3-48 mathematical-action correspondence.
