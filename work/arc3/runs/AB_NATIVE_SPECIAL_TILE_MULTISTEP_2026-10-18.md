# A/B native special tile: frozen longer visible-state continuation tests

Native source: original official ARC-AGI-3 LS20 raw pixel frames, not REA, a simulated replacement or an inferred F3 mathematical state. The original terrain-passability hypothesis is **still falsified** at the mixed-color 0/1/3 tile; this follow-up tests different propositions.

The earlier independently verified twelve one-action follow-ups (official run 39121963532, raw artifact 12135115409) showed three different eight-action histories — 11113323, 11113332, 33311413 — independently reaching the **same complete 64×64 visible frame** at row30,col19, source SHA16 94380564157962f5deb754fc81783a1d. In that separate earlier test, all four common next actions produced the same full successor frame across three source histories. That result does not prove hidden state identity or longer continuation.

This experiment source-pins original JSON/NPZ SHA256 for all four files of that earlier successful run, independently replays each of its twelve native raw paths against its source metadata, and verifies one-action whole-frame equality again before making any new observation.

### Predeclared held-out suffixes

Each of twelve words is applied after each of THREE histories, making 36 separately reset original native trial words. Frozen suffix words: 12, 21, 34, 43, 1212, 2121, 3434, 4343, 1234, 4321, 121212, 343434. Four are two-step departure-and-return hypotheses; others make longer routes or repeat the exits. The longest complete original native word contains 14 actions.

Three separate testable claims were written to source before native execution:

H1 — For equal suffixes starting from the exact same depth-eight original visible frame, the full actual native 64×64 frames remain **byte-for-byte identical at EACH later suffix step** for the three independent histories. This is 3 pairwise comparisons per suffix depth, 132 preregistered exact raw-frame comparisons.

H2 — Independently extrapolate the action-insensitive visible trace clock: at actual native depth t=9..14, native color-11 mask occupies precisely rows 61-62 and columns 13+t..54, with 84-2*t visible trace cells. This is 132 pixel-exact native trace predictions. This is NOT hidden state measurement.

H3 — For suffixes 12,21,34,43, the glyph returns to the observed tile at (30,19), while the whole visible frame differs from the original depth-eight frame due to elapsed trace-clock progression. This distinguishes **same visible glyph position** from **same full native visible state**. This is 12 separate held-out native roundtrip predictions.

The collector is the original official public native SDK and saves every intermediate 64×64 raw image, actual action, level, game-state label and independent reset. It does not score its own predictions. A separate verifier independently recomputes all source raw pixel hashes, checks exact common frame replay at depth eight, tests each of the three hypotheses separately and preserves failures/interruptions with raw frame source. If any claim fails, it leaves the scientific gate red, with no retrospective rule change.

This experiment cannot prove universal behavioral equivalence of hidden states, global native Markov sufficiency, native-to-F3 correspondence or a solved ARC game. Its only intended result is bounded visible continuation evidence for these original native histories and action suffixes. The original multi-edge falsification remains separate.
