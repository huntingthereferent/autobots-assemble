# A/B multiple unmeasured transitions in real native LS20

Owner-backed source: actual native ARC-AGI-3 LS20 frame/action records, not REA or an F3 identification.

The source freeze authenticates original pinned data for 27 initially learned native glyph/action transitions, the first 18 new transitions, and the subsequent complete 39-edge frontier, including raw 64x64 pixels, action metadata and SHA256. This produces 84 original verified native edges and 27 glyph positions reachable using those edges.

The ORIGINAL source-visible map rule stays fixed: the full 5x5 destination must be traversable native colors 3 or 5 for a five-pixel native action shift, otherwise motion is blocked. Missing raw observations are never silently created.

The new experiment enumerates all 52 action words containing TWO successive edges unmeasured by the old 84-edge graph. The first new action must reach a position not exposed by a previously observed outgoing action. Separately, 120 three-consecutive-unmeasured-edge paths are possible. Exactly 12 are selected using a deterministic source-defined sampling rule before any native action is executed. All 64 chosen words are frozen before measurement.

Each word starts at a freshly reset official native LS20 environment, follows a known verified prefix, then takes two or three formerly unknown steps. Every actual native intermediate frame is saved, and a separate verifier rehashes and independently checks raw pixels and scores the predicted positions, preserving a false prediction with source details if the fixed rule fails.

A passing result would support compositional predictions beyond the original one-new-edge frontier for this bounded visible map. A failure will be preserved and reported without adjusting the prior hypothesis. Neither outcome proves universal A/B, source F3 correspondence, complete hidden state or game completion. Original REA branch and main remain unchanged.
