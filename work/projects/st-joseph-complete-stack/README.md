# St. Joseph Complete-Stack Benchmark

## Referent

**St. Joseph, Missouri as a living physical / social / technical system.**

This is the first benchmark intended to make the Complete Stack architecture survive contact with a large real-world referent.

The objective is not to write a city profile.

The objective is to:

1. bound an initial evidence set;
2. traverse the relations that evidence actually opens;
3. emit working artifacts;
4. freeze the first-pass representation;
5. compare it with deeper real-world evidence that was not used to construct it;
6. preserve mismatches;
7. traverse the mismatches and regenerate affected artifacts.

## Benchmark shape

```text
PASS-0 public evidence boundary
→ system landscape
→ dependency decomposition
→ quantitative / spatial / executable artifacts as reached
→ freeze predictions / representations
→ REALITY CHECK with deeper evidence
→ DIFF
→ PASS-1 reconciliation
→ repeat
```

The first pass deliberately does **not** ingest every available GIS layer, engineering document, asset inventory, traffic count, budget, or operational dataset. Those can become reality-check evidence later.

## Critical boundary

A city is not one object with one completion state.

Each reached relation keeps its own witness depth.

A public planning document can witness that a system or responsibility exists without witnessing every physical asset, current condition, capacity, failure mode, or measured performance.

No map, diagram, plan, model, or public statistic is upgraded into physical measurement merely because it describes the real city.
