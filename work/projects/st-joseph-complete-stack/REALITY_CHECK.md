# Reality-Check Contract

PASS-0 is frozen before deeper evidence is admitted.

For each later comparison preserve:

| Relation | PASS-0 prediction / representation | Reality-check evidence | Difference | Cause class | Downstream invalidation |
|---|---|---|---|---|---|
| | | | | | |

Cause classes may include:

- missing dependency;
- wrong relation;
- wrong boundary;
- stale source;
- incorrect assumption;
- inadequate decomposition;
- quantitative model error;
- geometric model error;
- measurement/source disagreement;
- representation was correct but too coarse.

Do not edit the old prediction to make the diff disappear.

A correction belongs in PASS-1 with a link back to the mismatch that forced it.
