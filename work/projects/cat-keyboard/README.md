# Meow Lab 2 · local sound import and cat music studio

[Open the keyboard](../../../docs/live/cat-keyboard.html) · [Workstation](../../../docs/live/work.html) · [Visual provenance](../../../docs/live/visual-provenance.json)

This is a new 13-key cat instrument built *around source movement*. It is not the original purple Meow Machine page rebranded. It has a new dark research/audio look, an actual four-slot audio bank, waveform display, local sound imports, four MIDI-tuned cat voices (restored from Rosey’s kawaii keyboard), and source-backed repitching for imported samples in the keyboard, recorder and 16-step sequencer. Everything in the public browser runs locally without account credentials or hidden network endpoints.

## Built-in voices versus imported sound bank
The default Miso, Mochi, Nori and Bean keys now use the tuned Web Audio oscillator patch from Rosey's keyboard: MIDI-accurate fundamentals, voice-specific swoop, harmonic blends, two moving mouth-formant filters and delayed vibrato. Chord accompaniment uses the same patch with gentler voicing. The built-in sound-bank waveform and PCM handoff are generated by offline rendering this same patch at middle C (C4), when OfflineAudioContext is supported. The old mathematical sample is a preview fallback only in browsers without offline rendering.

**Imported WAV/MP3 clips are not replaced**: selecting a user sample overrides that cat slot until reset, and keyed sample repitching, download and native source handoff remain available. The workstation native verification boundary is unchanged.

## Two distinct paths for a sound

**Browser, immediately:** select a slot, choose an authorized local audio file, choose an offset and press Import Into Slot. The browser decodes the file, makes a bounded 2.6-second mono sample and maps it across the 13 keys. It displays the source filename and SHA-256 when available. This is a source observation, not a verified native worker. Press Export PCM16 WAV + Manifest to download an 8192-frame/16kHz mono source plus input receipt. If your browser blocks one of the two downloads, permit local downloads or try again.

**Actual native workstation:** run the exported WAV through the existing copy/admit/execute/host-replay/record pipeline, or batch-ingest four PCM16 WAV files named by slot. The standalone browser never executes private Python code and never falsely calls a DOM click a native PASS.

```sh
python -m systems.workspace.audio_sound_bank \
  --data-dir runtime/data \
  --source-dir /path/to/my/cat-wavs \
  --output-dir /path/to/my/verified-sounds \
  --version meow-sounds-v1 --semitones 5 \
  --copy-source --execute
```

The source directory must contain between one and four of `miso.wav`, `mochi.wav`, `nori.wav`, `bean.wav`. Native audio accepts ordinary non-symlink 16-bit mono WAV files with a sample rate from 8–96kHz and at least 128 frames; it moves at most 8192 source frames per file. **The bounded output can be imported back into Meow Lab 2**. Use a new version name when doing a new edition copy. The output includes native-reverified PCM WAVs, per-slot SHA-256 records, exact job IDs, and `sound-bank-manifest.json`. The native runner is invoked explicitly; it does not host a service.


## Real chord progressions and Rosey's keyboard

The integrated [Meow Lab 2 keyboard](../../../docs/live/cat-keyboard.html#harmony) now includes nine defined four-chord progressions and transposition into all twelve keys. A four-chord template can be entered by name (for example, `Am F C G`), saved locally, deleted, or backed up/restored as bounded JSON. The sixteen-bar arrangement retains independent chords and four original production-layer toggles per bar, but its **melody is exactly eight editable bars**, each with sixteen steps, repeating for arrangement bars 9–16. Playback advances through sixteen arrangement bars while reading melody 1–8 twice. The four-chord template fills only the selected group of four bars; selecting a modern template also installs an original layer timing structure for those four bars. Browser storage is not a native workstation event or a cross-device sync.

[Rosey's Kawaii Cat Keyboard — tuned higher-notes edition](../../../docs/live/roseys-cat-keyboard.html) is separately preserved as a standalone browser instrument with a scrollable 25-key, two-octave keyboard, tuned kawaii meows, built-in and saved chord progressions, and recording. It remains independent of the native sample import bank; Meow Lab 2 is still the workstation-linked sound intake instrument. Both run locally in the browser, without uploading a child's performance.


## Finite sixteen-bar arrangement branches

Each of the sixteen arrangement bars is an independently editable chord (including rest) and four production layers. The melody is **eight shared bars**, each with five rows of sixteen sixteenth-note steps. Arrangement bars 9–16 read the same eight melody bars again; the bar selector makes that alias explicit. The bar strip shows all sixteen bars; Previous/Next, click-to-select, and the optional Follow playback setting move the editor among them. The 16-step editor changes the corresponding looping melody bar (1–8); selecting bar 9 edits the same melody pattern as bar 1. Playback starts at that bar, traverses forward, and can either loop the whole sixteen bars or stop after bar 16. Copy previous bar copies the chord and layer structure, and on bars 1–8 also copies the melody. Clearing or replacing a melody pattern applies to its shared melody bar, including when accessed from arrangement bars 9–16.

The former throwback library is replaced with **nine modern original chord-and-groove archetypes**: bright pop, vocal pop, alt-pop, dance-pop, R&B, melodic rap, country-pop, synth-pop and indie-pop. User-created chord templates remain available. Applying a modern template changes **only the selected four-bar section** (bars 1–4, 5–8, 9–12 or 13–16), setting its chords and per-bar rhythmic-layer profile. Applying a user-created chord template changes chords only. The eight melody bars are never overwritten by progression generation.

The **saved arrangement branches** are independent local snapshots with sixteen chord/layer bar states, all legacy bar data, and tempo. The eight-bar melody is stored in melody bars 1–8 within the same backward-compatible 16-bar JSON format. Legacy melody notes in bars 9–16 are retained as dormant data for recovery, never played or silently deleted; audio now consistently loops the first eight melody bars. Save as new forks the current working arrangement; Update selected is an explicit overwrite of a chosen saved branch; Load selected restores it. There is a strict 24-saved-branch limit, a schema-validated JSON backup/restore format, and a copy of the unsaved working arrangement in each export. No browser save implies a native worker execution or a remote repository write.


## Pin melody edits and move chord cadence

The eight-bar melody now has eight direct M1–M8 edit-pin buttons above the melody grid. Selecting a melody pins it: the **arrangement playhead, chords and layers continue advancing** without moving the note editor out from underneath the musician. Unpin to return to Follow playback. Previous/Next melody navigation, copy previous melody and a bounded 24-edit one-level-at-a-time undo stack make it easier to develop a melody. Selecting an arrangement bar while pinned updates the pinned melody; the song's active playhead remains independent. Undo is session-scoped, not part of persistent branch snapshots.

Each of the **16 arrangement bars has its own editable 16-step chord cadence**. Instead of one frozen chord attack at every bar start, the synth releases and retriggers the current chord at each selected attack. Choose Sustain (1), Half notes (2), Quarter notes (4), Offbeat (4), or Syncopated (5), and/or edit each of the sixteen attack steps individually; Copy previous cadence copies just the rhythm. Chord cadences are not forced to match the melody's eight-bar cycle. Modern progression generation includes a genre-derived default cadence per bar; user-created chord templates continue to change chords only.

The existing `meow-machine/arrangement-branches-v1` JSON format remains readable and writable. Each newer bar adds an optional sixteen-boolean `cadence` field; **older saved branches without cadence retain their original once-per-bar sustain**, while newly constructed bars begin with a two-hit half-note rhythm. A strict 16-element boolean validator rejects invalid cadence data. Saving/updating/exporting a branch includes the current cadence of all 16 bars alongside chords, production layers, shared melody slots and tempo. This affects the public browser instrument only, without claims of native audio verification.

## Modern layer-structure study (July 21 – October 21, 2026)

This is a **structural abstraction**, not a transcription, stem extraction, or replica of a chart song. The observation window was July–October 2026. Chart snapshots show pop, R&B, country, rap and dance/indie tracks coexisting in the high-visibility singles mix, including *Billboard Hot 100* October 17 and UK chart snapshots from August and September. Those charts document popularity, **not** the chords, note sequences, or production stems of individual recordings.

The independent September 2026 ChordSonic user-submission study reported I–V–vi–IV as the most common four-chord loop in **its uploaded-song sample** (about 20% of detected four-chord loops). Its sample is not a radio/streaming chart. A September 2026 browser-studio production guide describes the recurring architecture of simple repeating harmony, a supporting groove and backbeat, bass rhythm linked to the kick, a hook, and energy changes between sections.

From these observations, the instrument builds **nine original reusable symbolic combinations** of four-chord movements and four layers: **pulse** (kick-like transient), **percussion** (backbeat/hi-hat-like transient), **bass** (root-based synth), and **atmosphere** (light high-register tone). The four rhythmic patterns in each profile are original 16-step events; section density varies by group of four arrangement bars. Each layer can be disabled independently per bar and is generated locally in Web Audio. The musician's own eight-bar melody stays separate and repeats through the sixteen-bar arrangement. There are no commercial stems, chord claims about specific tracks, copyrighted hooks, audio downloads from charts, or external model calls.

Three concrete **source-described layer relationships** in the time window helped shape the archetypes; their descriptions are not stems:
