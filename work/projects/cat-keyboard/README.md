# Meow Lab 2 · Swallow Sounds cat keyboard

[Open the keyboard](../../../docs/live/cat-keyboard.html) · [Workstation](../../../docs/live/work.html)

This is a new 13-key cat instrument built *around source movement*. It is not the original purple Meow Machine page rebranded. It has a new dark research/audio look, an actual four-slot audio bank, waveform display, local sound imports, four MIDI-tuned cat voices (restored from Rosey’s kawaii keyboard), and source-backed repitching for imported samples in the keyboard, recorder and 16-step sequencer. Everything in the public browser runs locally without account credentials or hidden network endpoints.

## Built-in voices versus imported sound bank
The default Miso, Mochi, Nori and Bean keys now use the tuned Web Audio oscillator patch from Rosey's keyboard: MIDI-accurate fundamentals, voice-specific swoop, harmonic blends, two moving mouth-formant filters and delayed vibrato. Chord accompaniment uses the same patch with gentler voicing. The built-in sound-bank waveform and PCM handoff are generated by offline rendering this same patch at middle C (C4), when OfflineAudioContext is supported. The old mathematical sample is a preview fallback only in browsers without offline rendering.

**Imported WAV/MP3 clips are not replaced**: selecting a user sample overrides that cat slot until reset, and keyed sample repitching, download and native source handoff remain available. The workstation native verification boundary is unchanged.

## Two distinct ways to swallow a sound

**Browser, immediately:** select a slot, choose an authorized local audio file, choose an offset and press Swallow Into Slot. The browser decodes the file, makes a bounded 2.6-second mono sample and maps it across the 13 keys. It displays the source filename and SHA-256 when available. This is a source observation, not a verified native worker. Press Export PCM16 WAV + Manifest to download an 8192-frame/16kHz mono source plus input receipt. If your browser blocks one of the two downloads, permit local downloads or try again.

**Actual native workstation:** run the exported WAV through the existing copy/admit/execute/host-replay/record pipeline, or batch-ingest four PCM16 WAV files named by slot. The standalone browser never executes private Python code and never falsely calls a DOM click a native PASS.

```sh
python -m systems.workspace.audio_sound_bank \
  --data-dir runtime/data \
  --source-dir /path/to/my/cat-wavs \
  --output-dir /path/to/my/verified-sounds \
  --version meow-sounds-v1 --semitones 5 \
  --copy-source --execute
```

The source directory must contain between one and four of `miso.wav`, `mochi.wav`, `nori.wav`, `bean.wav`. Native audio accepts ordinary non-symlink 16-bit mono WAV files with a sample rate from 8–96kHz and at least 128 frames; it moves at most 8192 source frames per file. **The bounded output can be imported back into Meow Lab 2**. Use a new version name when doing a new edition copy. The output includes native-reverified PCM WAVs, per-slot SHA-256 records, exact job IDs, and `sound-bank-manifest.json`. The native runner is invoked explicitly; it does not host a service.


## Real chord progressions and Rosey's keyboard

The integrated [Meow Lab 2 keyboard](../../../docs/live/cat-keyboard.html#harmony) now includes nine defined four-chord progressions and transposition into all twelve keys. A four-chord template can be entered by name (for example, `Am F C G`), saved locally, deleted, or backed up/restored as bounded JSON. The sixteen-bar arrangement has its own 16-step melody and chord for **each** bar, totaling 256 sixteenth-note steps. Playback advances bar by bar through the full composition; it does not repeat the first four chords unless you choose to arrange that repetition. Four-chord templates fill only the currently selected group of four bars. Browser storage is not a native workstation event or a cross-device sync.

[Rosey's Kawaii Cat Keyboard — tuned higher-notes edition](../../../docs/live/roseys-cat-keyboard.html) is separately preserved as a standalone browser instrument with a scrollable 25-key, two-octave keyboard, tuned kawaii meows, built-in and saved chord progressions, and recording. It remains independent of the native Swallow Sounds bank; Meow Lab 2 is still the workstation-linked sound intake instrument. Both run locally in the browser, without uploading a child's performance.


## Finite sixteen-bar arrangement branches

Each bar is an independently editable chord (including rest) plus five melodic rows of sixteen sixteenth-note steps. The bar strip shows all sixteen bars; Previous/Next, click-to-select, and the optional Follow playback setting move the editor among them. The 16-step sequencer always edits only the selected bar. Playback starts at that bar, traverses forward, and can either loop the whole sixteen bars or stop after bar 16. Copy previous bar, clear bar and replace the current bar's pattern are bounded local edits.

The nine four-chord templates and any user-created chord templates remain available, but applying one changes **only the selected four-bar section** (bars 1–4, 5–8, 9–12 or 13–16); all other chords and per-bar note patterns remain untouched.

The **saved arrangement branches** are independent local snapshots with sixteen complete bar states and tempo. Save as new forks the current working arrangement; Update selected is an explicit overwrite of a chosen saved branch; Load selected restores it. There is a strict 24-saved-branch limit, a schema-validated JSON backup/restore format, and a copy of the unsaved working arrangement in each export. No browser save implies a native worker execution or a remote repository write.
