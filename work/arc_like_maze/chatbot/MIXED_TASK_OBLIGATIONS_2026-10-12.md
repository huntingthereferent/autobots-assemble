## Distinct witness contracts

- **EDGE:** The source state and labeled action appear in the single selected, fully replayed partial extension's admitted edges.
- **PATH:** Every labeled transition along the required rooted word is admitted **in that same pairing** and both specified old/new final states match replay of the entire word. Equality of endpoints alone does not witness a specified history.
- **DESTINATION:** The specified old state is paired with the required changed-state image, with an admitted rooted history. This obligation does not substitute for an EDGE or PATH witness.

The opt-in integrated source is `ab_chatbot_mixed_obligations.py` in the separate full archive. It supports strict structured declarations for 1–8 source goals, 0–8 required edges, 0–8 distinct paths (A/B words length 1–8), and 0–8 destination identities. An accepted mixed contract must include a path or destination. The earlier goal-only/single-edge/plural-edge exact text and structured task inputs still use the unchanged prior session. Unsupported prose remains UNKNOWN_TASK. An internally contradictory path endpoint and requested destination image is INCONSISTENT_TASK without any observations.
