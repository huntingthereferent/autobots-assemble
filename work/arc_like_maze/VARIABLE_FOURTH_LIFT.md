## Current referent

The preceding [fifth-coordinate theorem](FIFTH_COORDINATE_LIFT.md) fixed a quadratic fourth-coordinate quotient `Q(w)=w²`, with zero additional row offsets. It proved exactly 81 admissible fifth-coordinate coupling tables and retained an order-nine commuting map.

The present construction varies **all fourth-coordinate quotients Q of nonzero trace** and both independent normalized row offsets. The central question is whether the previous rank-five compatibility result and order-nine cyclic structure persist.

This is a finite-field transformation system generated by explicitly defined transformations A and B, not a general-purpose A/B algorithm and not native ARC gameplay.

## Exact family of fourth-coordinate rules

Keep the two previously admitted nonconstant lower couplings:

```text
g=1: q0 rows (0,1,2), (0,2,1), (1,1,1); alpha=(0,1,1)
g=2: q0 rows (0,1,2), (1,0,2), (1,1,1); alpha=(0,0,1)

w=phi(v,z)=z+alpha(v), with v=x1 and z=x2.
```

Admit fourth-coordinate couplings of the already characterized form

```text
q1(v,z)=Q(w)+k(v)
Q:F3 -> F3, k:F3 -> F3, k(0)=0.
```

The correction that translates x2 by one has fourth-coordinate increment

```text
h(w)=Q(w)-Q(0).
```

Its third-iterate trace equals `sum_w Q(w)` modulo three. Retain only **nonzero trace** so that the preceding corrected transformation genuinely has order nine at dimension four.

There are 18 such functions Q out of 27, and nine independently normalized offset functions k. For each gain, this gives **162 fourth-coordinate configurations**; both gains together give **324**. These are configurations of transformation laws, **not** a count of conjugacy classes.

The fifth-coordinate coupling `q2(z,y)` is any nine-entry function of `z=x2` and `y=x3`. All subsequent couplings vanish.

## The fifth-coordinate cohomological equation

On the 27 lower-coordinate states `s=(v,z,y)`, let

```text
E_u(v,z,y) = (
    v+g*(u+1),
    z+q0(u,v),
    y+Q(w)+k(v)
)

C_lower(v,z,y)=(v,z+1,y+h(w)).
```

The proposed transformation retains `C_lower` and adds `L(v,z,y)` to x4. It commutes with the first generator automatically because L does not depend on x0. Commutation with the second generator is **exactly**

```text
L(E_u(s))-L(s)
   = q2(C_lower(s))-q2(s)
for all 3 choices u and all 27 lower states s.
```

Thus there are 81 linear equations over `F3`. The unknowns consist of 27 correction values `L(s)` and nine coupling-table entries `q2(z,y)`: **36 variables**.

Direct elimination, or equivalently reduction of the signed-voltage graph, gives three distinct ranks of the resulting constraints on q2. The full lower graph is connected for all 324 order-nine configurations, so the solution for L is unique up to adding one global constant.

The total number of admissible fifth-coordinate combinations is **4,050 per gain**, or **8,100 across both gains**. These are admissible (fourth-coordinate configuration, fifth-coordinate table) combinations, not new equivalence classes.

For gain one, the same nonconstant quotient `Q=(0,0,1)` illustrates all three ranks:

```text
offset k=(0,0,0) -> rank 5 -> 81 admitted q2 tables
offset k=(0,1,1) -> rank 6 -> 27 admitted q2 tables
offset k=(0,0,1) -> rank 7 ->  9 admitted q2 tables
```

The exact offset fixtures differ for gain two. The [implementation](variable_fourth_lift.py) derives the rank instead of assuming the same offsets yield the same result across gains.

A new structural boundary appears at **rank seven**: every admitted table is independent of y, in fact of the form `q2(z,y)=a*z+b`. Thus rank seven admits **no genuine dependence on the preceding fourth coordinate**. Ranks five and six admit some genuinely y-dependent couplings.

## The order-nine closure survives — without presuming it

For any accepted q2 the signed graph equation yields an explicit correction L. Whether the resulting transformation has order 9 or 27 is a separate question.

The previous lower transformation has exact order nine, so after nine applications x0 through x3 return to their original values. The fifth-coordinate displacement is the orbit sum

```text
S(s)=sum_(i=0)^8 L(C_lower^i(s))   mod 3.
```

The map from q2 to its normalized correction L is linear. Every admissible q2 is a linear combination of nullspace basis vectors; adding an arbitrary constant to L changes S by nine times that constant, which is zero in F3. Therefore it suffices to verify the orbit sum on a basis for each of the 324 exact finite linear systems.

The basis proof checks **816 independent q2 basis vectors** at all **27 lower states**, with zero nontrivial nine-turn displacement. It also checks the single constant gauge direction per configuration. The direct, independently written 81-by-36 matrix verifier reproduces the same result from scratch.

Consequently **all 8,100 admitted fifth-coordinate combinations preserve exact order nine**. No order-27 extension occurs within this specified family. This statement does not prohibit order-27 transformations under different higher couplings, different correction coordinates, or other centralizer constructions.

## Literal mathematical certificates

For a rejected fifth-coordinate q2, the executable classifier gives a **signed-cycle obstruction**: two verified paths through the induced 27-state graph have identical endpoints but require different accumulated values of L. This is an obstruction to the specified additive correction, not to arbitrary bijections.

For an admitted q2, the classifier supplies a complete 27-value correction L, from which the exact map on every finite dimension is generated. Its inverse is its eighth iterate. A five-coordinate distinguished point is transported explicitly; inverse and composition retain literal exponents, and a transformation that moves the point is never silently treated as an automorphism fixing the original marked point.
