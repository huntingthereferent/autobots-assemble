## Finite-field transformation system

At a chosen dimension `d`, the state set is `X_d = F_3^d`, where `F_3 = {0,1,2}` and arithmetic is modulo three. A system consists of two specified invertible transformations:

```text
A_d : X_d -> X_d
B_d : X_d -> X_d
```

Invertibility permits an action of the free group on two generators; the programs here also examine positive words in the free monoid. A pointed system additionally specifies `m_d ∈ X_d`, often the zero state. Projectively compatible systems define a corresponding action on the inverse-limit state space.

A full-state conjugacy `F : X_d -> X'_d` satisfies:

```text
F ∘ A_d = A'_d ∘ F
F ∘ B_d = B'_d ∘ F
```

A pointed conjugacy must **also** satisfy `F(m_d)=m'_d`. Conjugacies between the underlying state spaces do not automatically conjugate the original distinguished points.

## Composition order in the existing Python research

The interpreter processes a string of generator symbols **from left to right**:

```python
for symbol in word:
    state = step(state, symbol)
```

Standard function-composition notation therefore reverses the order of the literal string. Preserve this translation in every mathematical report:

| Python literal | Mathematical composition (rightmost acts first) |
|---|---|
| `B` | `B` |
| `BBB` | `B^3` |
| `AABAB` | `B ∘ A ∘ B ∘ A²` |
| `ABABAB` | `(B ∘ A)³` |

These strings are **implementation encodings** of mathematically defined compositions, not the preferred names of the results.

For any composition `w`, its fixed-point invariant is `#Fix(w)=|{x∈X_d:w(x)=x}|`. Equality of a finite selection of fixed-point invariants does not establish conjugacy. A mismatch obstructs conjugacy; a positive classification needs an explicit bijective intertwining map or a complete sound isomorphism procedure.

## Operator terminology

For a transformation system generated by `A` and `B`, its centralizer comprises bijections commuting with **both** generators. A coordinate translation `T_r` is a centralizer symmetry only when the relevant coupling rules satisfy the proved invariance equations. A symmetry of the unpointed system can send the originally distinguished point to a different point. Representing that transformation as an arrow of *pointed* systems requires an explicit target mark.

The term **closed** always names a precise construction or operator family and the operation under which it is closed. Neither finite test counts nor an orbit of order three prove universal inverse construction, native ARC completion, or a universal stopping theorem.
