# Rooted A/B inverse observations — no change of referent

The original 48 source laws have **14 unpointed full-state classes** but **16 root-preserving classes**. An unpointed word fixed-state count can never distinguish laws connected by an unpointed conjugacy. The previous inverse investigator therefore stopped at two six-law classes rather than guessing away the distinction.

This extension introduces a distinct observation: whether two A/B words starting from the marked mathematical origin **land on the same state**. This is an invariant of rooted (origin-preserving) conjugacy; it need not be preserved by a conjugacy moving the origin.

## How evidence moves

The new source-owned module uses original CombinedWorld.apply, classify_pair and rooted_conflict. Its catalogue of admitted word pairs is **constructed from those original all-depth nonrooted-conjugacy witnesses**, replayed and verified against the source transitions.

The investigator takes fixed-count observations first. When only unpointed-equivalent but rooted-distinct candidates survive, it proposes a rooted word pair, partitions the surviving laws by predicted endpoint equality, and waits for **explicit admission of a boolean observation**. It does not assert which prediction was observed. Contradictions, unauthorised word pairs and conflicting repeat evidence fail closed.

An independently executed synthetic mathematical oracle supplies observations only in the tests or clearly labeled --demo-law mode. Across all 48 original laws, the combined procedure reaches 16 classes of three shear-equivalent laws. Each of the twelve laws inside the two ambiguous sextuples requires at most one additional rooted equality observation; the other 36 need none. This class conclusion is within the declared finite source family—not unique identification of a shear-chart coefficient.

The executable certificate verifies every original class and real source witness; the program has no REA dependencies, no native ARC state mapping, and makes no universal Language Referent claim.
