# Trial 11 — hypothetical discrimination is not an observed contact

Original WORLD Trial10 preserves three possible contact-active-set evaluations
for every one of 35 source/controlled geometry cases. Trial11 asks what
*additional evidence* could distinguish the surviving candidates, without
inventing physical readings or deciding real-world contact activation.

The original Trial11 source tests (a) a **necessary, not sufficient**
mu=0.4 Coulomb friction-cone bound applied to the frictionless candidate
impulses, (b) an **extra, unobserved** all-touching-normals restitution
postulate, and (c) 3 virtual sample times × 3 quantized position bins for
each case. Source records show a matching hypothetical sample *could*
separate candidate predictions; there are no actual sensor observations.

The A/B handoff checks out pinned WORLD Trial11 commit
`ec2522164c2dc85f906d211fc780061171fd5e71` and executes its original
native results and independent source verifier, along with native regressions.
It then records all 35 case identities, source-reported candidate audits and
**315 source-proposed sensor settings** in a separate general-world layer.
Every proposed sample is an object and a source-attributed record explicitly
labelled hypothetical, with `measured_reading: null` and no outcome selection.

The five independently verified bounded A/B ledgers correspond to the five
predeclared surface rotations. Each records seven original source cases and
63 possible sensor readings; a source-linked ordered hash manifest joins
their provenance. This preserves the shared 1MB-per-plan limit without
pretending to form one unbounded mutable event chain.

Source-native results (previously checked by the original browser trial):
26 ambiguities, 0 narrowed using the necessary cone bound, and 26
ambiguous cases with potentially discriminating hypothetical position
measurements at the tested settings. The extra restitution postulate
narrows/eliminates candidates only *conditional on that unobserved law*.

None of these observations is an external physical measurement, an
instrument-verified source, or a demonstrated frictional manifold solver.
Ledger verification proves the record's consistency, not the source's
mechanics. Source-native verification is separately required to support
the stated virtual-model claims.

No original WORLD source branch, W13, ARC, NIH, World48, renderer,
A/B licensing, or general construction rules are changed. Continue by
testing what observation would actually exist and which bounded candidate
relationships remain supported if such readings become available.
