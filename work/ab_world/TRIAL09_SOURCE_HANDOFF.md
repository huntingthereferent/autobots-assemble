The original WORLD Trial09 experiment follows the Trial07 simultaneous
arrival and Trial08 conditional frictionless candidate. It constructs the
predeclared **seven incidence directions by five surface rotations** and
checks thirty-five resulting cases. The original trial owns the geometry,
frictionless candidate law, rejections and independent physical-model checks.

Only the zero-rotation cases reuse the **unchanged original two source faces**.
Rotating face B creates explicit controlled counterfactuals with source-parent
identity; those are never promoted into newly observed source material.
Every case retains its status, input geometry and source report.

The A/B carrier keeps the unresolved original frictional junction separate
from the Trial08 frictionless model and from all Trial09 controls. For
accepted candidate cases it records all 31 time-ordered frames as candidate
object revisions. For rejected cases it stores the reason and observation
but emits **no trajectory**. It checks the declared grid order and original
counts, then independently reconstructs the complete ledger. Nothing in
the neutral layer selects an impulse or enforces physical contact equations.

The dedicated CI job runs original native source commit
`e1679c4dd7b810e0539bc619ace32f0fea67814d` in a separate checkout,
executes original WORLD Trial09 and prior-regression test modules plus their
independent mathematical verifier, then carries the native source JSON into
the general A/B ledger. Native source evidence and ledger witness evidence
are retained separately, with file hashes. The source trial's original
browser experiment remains separate and is not claimed as newly replayed
by this CI.

**Limits:** the candidate is frictionless and conditional; original
frictional simultaneous-contact mechanics remain unresolved. Rotated source
geometry is explicitly synthetic. No external instrument authentication,
real material behavior, general two-contact law, or physical blueprint has
been demonstrated. A source code SHA-1 commit pin or an unsigned SHA-256
digest is not third-party attestation.

not modified by this adapter. Follow-on experiments should investigate the
