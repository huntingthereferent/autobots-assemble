# WORLD Trial17 — locate first renewed square contact, leave impulse unknown

The original WORLD Trial16 source found sampled penetration of the original
finite wall during proposed freely rotating-square movement. Trial17 refines
that evidence: it evaluates four square-vertex signed-distance functions
against the ORIGINAL finite wall, partitions the 0.06-second observation
interval at each function's stationary times, then uses numerical bisection
to locate the earliest later positive-to-negative crossing.

The unchanged original WORLD Trial17 source is pinned to commit
`02b2f6ca97717eb3bf959d120a2c32a6ae856543`. Its independent original
oracle rechecks proposed contacts by directly rotating the original four
vertices on a dense, independently chosen time grid; it does not call the
generator's stationary-partition function. Six angles yield **numerically
bracketed finite-interior recontact candidates**. Angles 0° and 20° yield
no new line crossing in the declared 0.06-second window. No crossing in
that window is NOT continuous clearance or an assertion of no later contact.

The A/B source-specific carrier preserves all eight source reports and
root lists as **eight independently bounded evidence records**. It begins
with the unchanged original modeled first-impact witness, introduces a
bounded first-return *investigation*, and records root-search results.
Only after a source-attributed return observation may a distinct finite
candidate-contact-location object be introduced and related to the
investigation. That object includes the original virtual time, source
vertex identity, signed normal vertex rate and finite face position.

A candidate-return object is **not** a receiver face, next impulse or
postreturn state trajectory. No new physical material was constructed.
Original-root numerical bracketing is not formal exactness or an external
instrument measurement. A no-return case creates no return-location object,
does not clear future motion, and does not select a physical result.
