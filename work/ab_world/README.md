# A/B world: first cross-referent source probe

This is a **read-only experiment against actual existing native programs**, not a new universal math/world engine, an autonomous worker, or a simulation of physical measurements.

## Question

Do we need to make the original W13 game larger or require World48 before we can examine an NIH temporal relation?

To test **that narrower prerequisite claim**, cross exactly two observed W13 movements with two independently chosen fictional knowledge cutoffs, preserving an identical clinical-validity target:

- Original W13 source: the untouched `game_construction.GameSpec`, `first_state` and `transition` functions. From the original 4×3 room, `left` hits a boundary while `right` moves a cell. These are real local **source computations** (not browser or physical observations).
- Original NIH source: load the existing `nih_scope_example.json` and execute the **original emitted** `prototype_worker.ENGINE` in a new isolated Python process at each knowledge cutoff; compare its visible/withheld ID sets with the separate original scope host oracle. Both observations are explicitly synthetic.
- Optional World48: replay one exact original A movement for two source-owned F3 laws with the already-existing `verify_receipt`. This remains mathematical source replay, not an NIH computation or a new W13 rule.

This yields **four crossed observations**, not a fourth dimension of the game or a claim of universal independence. Repeated W13 movement must remain identical when only NIH cutoff varies; the NIH result must remain identical when only a W13 direction changes. Early vs late knowledge **must** change the visible evidence, and `left` vs `right` **must** change the game outcome.

These controls intentionally **decouple** the inputs for a bounded comparison; they do **not** replace the already verified, separate original W13 browser game→NIH turn-clock integration.

## Witness and limits

The probe records source-file SHA-256 digests and the exact original emitted engine's SHA-256. It also refuses a calendar-invalid NIH query. Mutation tests reject changed NIH selection logic, invalidated original fictional source conditions and forged World48 steps.

The game and World48 replay use their **own original native code**, so this is not a separately implemented physical or general-world verifier. The NIH output is compared to the distinct pre-existing scope oracle, still within the same declared synthetic premise.

A pass answers only: **on these inputs there is no demonstrated need to enlarge W13 or install World48 as a prerequisite for temporal querying**. It does not establish completeness of the W13 representation, general temporal knowledge graph correctness, full OWL inference, real authenticated ClinicalTrials.gov historical version content, a physical motor, NIH Phase 2 completion, or NIH participation/award.

The original W13 source, twelve-job private journal, Phase 2 draft PR #158, World48 source, separate WORLD Trial 14 branch and shared runtime remain unmodified. No workflow automatically merges or changes the original native workers.
