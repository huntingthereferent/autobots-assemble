# Trial 14 — the receiver relation is constructed *through* movement

The original WORLD Trial14 source at commit
`344d419be87b737b7cc8af57fb8c680ce492beac`
investigates a single finite input source face whose controlled orientation
and anchor can move within explicitly bounded virtual geometry. The first
modeled contact changes the disc's outgoing velocity. Only **after that
contact** is a receiver face constructed from the outgoing direction and
finite travel projection. The subsequent receiver contact and source paths
are independently checked by the original native numerical oracle.

The original study declares eight source controls (angles 0, 7.5, 12.25,
20 degrees × friction 0 and 0.4), including original 04B controls.
All eight produce **two contacts in the declared mathematical model**.
A separately exercised finite source-segment miss produces no receiver and
no completed motion record.

The A/B carrier preserves the distinction between controlled inputs and
source-derived construction. For each of eight successes it introduces the
input face and moving virtual disc, then records the time-ordered source
frames. The first source contact is an attributed observation; **only then**
does the receiver object appear as a new object and a source-movement
relationship. The receiver is not preinstalled as an arbitrary target.
The second modeled contact is recorded against that newly derived face.

A ninth independent bounded A/B plan carries the deliberately missed source
as an observation with no receiver, no new contact, and no completed path.
Original source receipt digests and each of the nine independently verified
finite ledgers are tied by an ordered manifest, respecting the existing
1MB-per-plan limit.

The native source and independent oracle, not the general A/B ledger,
verify modeled finite-segment geometry, first/second impulses, energy,
spin, event positions and nonpenetration. No copied source solver is
embedded in the A/B adapter. A/B ledger replay verifies event ancestry
and data consistency, not physical law.

These are finite **virtual source-owned** movements. The inputs are
experimenter-declared controls, and the derived receiver is a mathematical
object, not grown real-world matter. They do not prove a general contact
solver, arbitrary shape generation, NIH physical blueprint equivalence,
motor assembly or Earth-material behavior.
