# Language Layer

Language is an interface over movement, not the movement itself.

The same underlying referent/movement may be expressed in different human languages, registers, slang systems, technical vocabularies, or machine encodings without requiring a new network state.

```text
surface utterance
      ↓
native pragmatic interpretation
      ↓
candidate movement shape
      ↓
context / referent / evidence check
      ↓
language-neutral shape ID + modifiers
      ↓
optional rendering through another surface/lens
```

## Rules

- Same words do not guarantee same meaning.
- Different words can preserve the same movement.
- A shape ID is a provisional operational handle, not the permanent identity of an utterance.
- Slang/register information is preserved as pragmatics rather than discarded as noise.
- Decoding language does not itself create network movement.
- Rendering language does not itself create network movement.
- If several meanings remain live and the difference matters, preserve ambiguity and clarify rather than forcing one shape.

English is the first rebuilt language bank. Future languages map into the same neutral shape IDs where the movement actually corresponds.

## Activation routes

Some expressions are deliberately registered as compact entrances into existing ecosystem state.

```text
surface + actor/context
→ explicit activation route
→ current referent + projection + selectors
→ existing handoff state
```

Activations are narrower than general language decoding. They do not infer a new meaning from similarity and they do not mutate state merely by being spoken.

The first registered route is:

```text
"ohayo" + James
→ James / current day
→ task queue
```
