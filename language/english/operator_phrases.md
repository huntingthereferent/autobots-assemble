# English Operator Phrases

These are short phrases the user can use as **movement operators** without needing to remember formal protocol names.

They are language surfaces, not new definitions of A/B.

## `swallow X`

Maps to: `LAYER.ABSORB`

Meaning:

> Fold a specialized child layer into the more general parent when it has no unique witness/evidence contract, while preserving provenance, compatibility, and any genuinely unique constraints.

Not delete. Not erase history.

## `dissect this`

Maps to: `ANALYZE.DISSECT`

Meaning:

> **Break apart and connect.**

Operational expansion:

```text
current referent
    ↓
decompose
    ↓
separate layers / parts
    ↓
trace provenance
    ↓
inspect each part in context
    ↓
connect only supported relations
    ↓
preserve UNKNOWN / unresolved distinctions
    ↓
reconstruct the useful whole
```

This is deliberately stronger than “summarize” or “explain.” It asks the AI to open the structure, preserve the layers, and reconnect them.

### Useful equivalent surfaces

- “break this apart and connect it”
- “pull this apart”
- “break it down and show how it fits”
- “crack this open”
- “map the parts and connections”
- caveman/telegraphic: “open thing. show parts. connect parts.”

If a phrase like “rip this apart” is clearly being used as critique, the decoder may choose a different shape. Context still resolves the surface.
