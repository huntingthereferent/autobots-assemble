# Language Network

A persistent external operating environment for using AI across work, research, tools, domains, and human language.

The repository is **not A/B itself**. A/B remains the recursively reusable mathematical operation and witness/evidence contract. This repository is an operational environment constrained by that shape.

## Major layers

- **A/B boundary** — mathematical invariant and witness/evidence constraint
- **network/** — append-only relations, snapshots, provenance
- **protocols/** — reusable contracts for movement
- **language/** — surface language ↔ language-neutral movement shapes
- **lenses/** — read-only projections of one unchanged snapshot
- **domains/** — domain-specific adapters above the generic contract
- **work/** / **jobs/** — actual work instances
- **evidence/** — frozen history, tests, artifacts, manifests
- **state/** — minimal current routing pointer

## English

English is the first rebuilt language bank. It includes standard, plain, casual, slang, internet, **caveman/telegraphic**, and technical registers.

The bank is not a dictionary. It maps surface forms to **candidate movement shapes**, then lets referent/context resolve the movement. For example, “send it” can mean **continue** or **submit** depending on the active referent.

## Output lenses

A lens changes representation, not state.

```text
same frozen snapshot
├─ raw lens
├─ JSON lens
└─ English lens
```

Rendering never creates network movement.

## Core rule

**current referent → admissible evidence → witness → movement/wall → provenance → continuation**

The representation may change. The underlying movement does not have to.
