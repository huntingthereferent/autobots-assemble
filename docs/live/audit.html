This is an inspection and annotation tool. It does not run tests, declare tests passed, audit private journals, or update the repository. Tests are discovered from tracked Python test-like paths, not from a fabricated status dashboard. Dynamic tests and tests using other naming conventions may be missing. Source SHA and line links are retained in exported reviews. An unavailable source is unknown, not evidence of absence.
