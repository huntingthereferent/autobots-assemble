# Tracework native evidence continuity

This GitHub development version must not rely on expiring Actions artifact URLs as the only copy of a native witness. Evidence must retain the original run, source commit, artifact name and content hash. Historical unsuccessful trials remain evidence, not successes.

The preservation path must be verified independently of the GitHub Actions artifact retention timer. The original ZIP and source-bound manifest must be retained together, and an archive-only operation must not execute or revise the experiment.
