# Source-generated motion

These animated SVGs are generated by the native research repository's render.py, not manually drawn or made with generative image software. The renderer is a read-only view.

| View | Native evidence source | Scope |
| --- | --- | --- |
| Finite A/B | [math.py](../../work/arc_like_maze/math.py) | Real World(3, (0,1,2)) endpoints for AB, BA, and A^3. A defined finite mathematical model, not a theory of human experience. |
| Workstation | [work_state.json](../work_state.json) | Recorded MOVE/WALL/UNKNOWN/PARTIAL counts, not live workers. |
| World observations | [latest.json](../world-continuity/latest.json) | Original GitHub–PyPI URL-metadata match if supported, and USGS intentionally unjoined. Preserves original timestamp. |

These GitHub-compatible SVGs use CSS animation. They continue moving as the reader scrolls past sections but do not respond directly to scroll position. GitHub README does not permit arbitrary JavaScript for scroll interaction. Reduced-motion preferences disable animation.

From repository root run: python -m unittest -v views.motion.test_render ; python -m views.motion.render

The workflow regenerates only when one of the actual source records or renderer changes, or when manually dispatched. A generated visual does not execute a worker, authenticate ownership or assert cross-domain correspondence.

After merging and generating on main, embed the SVGs from raw.githubusercontent.com/huntingthereferent/autobots-assemble/main/views/motion/ in the profile README, alongside the original source links.
