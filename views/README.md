# Views

`views/` contains read-only or generated projections over preserved state/evidence.

A view may change representation, audience, or aggregation. It may not mutate the underlying evidence or upgrade what was demonstrated.

Human-language interpretation/rendering belongs in `language/`.

Capability/resume/credibility summaries belong here or beside their source evidence when tightly scoped.

## Visual presentations

- [A/B finite mathematics workbench](ab-math-workbench/README.md) — actual 12-world finite movement and witness map, with an explicit external REA evidence boundary.
- [GitHub visual provenance concept](visual-provenance/README.md) — illustrative, source-linked README visualization of observation, separate histories, witness boundaries, and continuation; **not a live evidence feed**.
- [World continuity public observations](world-continuity/README.md) — scheduled, source-linked USGS/GitHub/PyPI observations projected with the **existing public-data-monitor adapters**, native metadata relation checks, poll history, and a GitHub-rendered SVG. [Open the latest collected source data](world-continuity/LATEST.md).

The former generic `lenses/` package was removed because its responsibilities are now covered by these explicit layers.
