# Workstation integration map — source-owned merge boundary

This map connects existing repository systems. It does **not** replace their
implementations, collapse their research claims, or assert that tests ran.

## Shared movement

source-owned evidence / experiment
→ source locator + explicit relation
→ `runtime/` handoff and evidence contract
→ `systems/workspace/` lane-return and cross-lane references
→ `systems/workspace/research_observatory.py` source observation
→ `docs/live/work.html` read-only execution projection

A view is not a source of truth. A committed implementation is not an execution
receipt. An A/B finite witness is not a proof of all systems.

## Merge rules

1. Reuse the existing `runtime/` handoff carrier and source-owned schemas;
   do not create a competing scheduler, event log or mathematical definition.
2. Every cross-lane relation names both canonical source paths and the exact
   witness needed before a claim changes status.
3. Keep `IMPLEMENTED`, `TESTED`, `OBSERVED`, and `UNVERIFIED` distinct.
4. Preserve existing historical trial records and current workers; integration
   should be additive and reversible.
5. Before routing new work, check the existing workstation pipeline audit:
   `systems/workspace/handoffs/workstation-pipeline-audit-2026-10-24.json`.
6. The 81-element group is a bounded F₃ witness and is not the top-level A/B
   referent or a replacement for ARC, WORLD, or other research.
