# Packaging comparison set — discovery input

The operator supplies comparisons. Tracework applies its existing finite
construction, movement, and evidence contracts. This file is not a second
discovery engine, a new ontology, or a claim of universal success.

## Relations to compare

1. Original ↔ packaged: identity and required relations preserved or lost.
2. Inside ↔ outside: inclusion boundary versus external dependencies.
3. Before ↔ after: transformations and invariants.
4. Known ↔ unknown: observed evidence versus unresolved relations.
5. Package ↔ receiving environment: actual usability in destination conditions.
6. Claim ↔ independent native observation: evidence for each required witness.

Each comparison must admit a counterexample. Absence of evidence is unresolved,
not automatically false and not a pass.

## Different realizations to probe

- A source repository packaged as a usable tool (existing A/B REA experiment).
- A smaller Tracework distribution with private source and a tested public-facing interface.
- A document collection requiring preserved references, order, and readable output.
- A dataset with schema, integrity, lineage, and an independent reader.
- A physical design with parts, assembly dependencies, units, and reproducible instructions.
- An unfamiliar object whose required relations and receiving environment are not known.

These are contrasting referents, not six separate packaging engines.
An adapter is permitted only when its actual source and native verifier are identified.

## Discovery operator handoff

For each referent, the operator provides:
- source observation and explicit packaging goal;
- proposed boundary and receiving environment;
- candidate relations to preserve;
- at least one negative/counterexample test;
- a source-owned verifier or an explicit unresolved verification requirement.

Then the existing workstation carries the work. Unknowns remain open comparisons;
no fabricated worker, evidence, or release status. A passing structural contract
does not establish a usable package.

## Acceptance

One unchanged core comparison contract across materially different shapes.
Each candidate must retain a traceable original, declared boundaries, and
source-specific independent verification. Rejected witnesses must not ship.
Unknown objects must remain investigable without assigning an invented format.
