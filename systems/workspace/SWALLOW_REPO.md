# Swallow Repo — named A/B workstation lane

**Referent:** Fix or reground actual repository source relationships, preserve
what survives independently witnessed corrections, and ship the result as A/B.

**Not the referent:** Copying a repository, copying its UI, adopting its
license, inventing a substitute bot, or presenting a visual provenance page
as the whole product.

This source-controlled lane document is a **return point**, not a fabricated
RuntimeJournal event or a claim that a local worker is running. Actual source
edition and action records belong to the real ProcessWorkstation and the
native CI evidence files.

### Entry point

- Supported source: pinned morluto/rea original JavaScript investigation code.
- Real source stages: observation, choice, novel input construction, advance
  and checkpoint (via existing ProcessWorkstation).
- Product CLI: ab source; ab swallow repo; ab inspect; ab ancestors;
  ab render; ab ship.
- Source owner rights: REA remains MIT on REA material, separately from the
  original A/B All Rights Reserved license and product distribution.
- Ship gate: source-stage receipts, original command-log digests, native REA
  tests, TypeScript check, visual provenance, A/B wheel, A/B sdist and the
  original docs landing page.

### Next movement

Add another actual source family only after a source-specific native adapter
has been inspected, corrected and tested. Keep the upstream source
identification and rights separate. No generic repository-copy operation
can count as successful swallowing.
