## Day-level source-conditional experiment

`BEFORE_OWNER_REPORTED_DAY`: the modeled source version would not yet be available, **conditional on the author's labelled Last Update Posted day**.  
`SAME_DAY_TIME_UNRESOLVED`: on that posting day, the public availability time within the calendar day is unknown; preserve both possible outcomes.  
`AFTER_OWNER_REPORTED_DAY`: the source version is model-eligible after its declared posting day; this is **not independently observed 2019 internet access**.

| Day-level query | Conditional possible latest version |
|---|---|
| 2019-08-01 | None |
| 2019-08-02 | None or V94 |
| 2019-08-03 | V94 |
| 2019-11-24 | V94 |
| 2019-11-25 | V94 or V105 |
| 2019-11-26 | V105 |

A static selection of V105 before its stated posted day is a **future-source-leakage counterexample** in this explicitly bounded two-version model. The original fields have the same `RECRUITING` values at both selected versions, so this test establishes **version availability/provenance movement**, **not a real recruitment-status change**. It cannot exclude uninspected intervening registry versions, withdrawals, or corrections.

## Source-boundary decision

**SUPPORTED:** Original public source version-specific *field identities*, their owner-reported posted **calendar days**, independent browser-body hashes, explicit conditional day-granularity model and separate enumerative oracle, actual original W13 playable browser clicks, unchanged native source evidence.

**NOT SUPPORTED:** Independently recorded original 2019 posting events; exact UTC first-publication instants or original time zone; original version availability at a particular hour of August 2 or November 25; all intervening version contents; verified patient/clinical outcomes; a new native temporal Python feature; Phase 2 NIH submission.

Keep **issue [#106](https://github.com/huntingthereferent/autobots-assemble/issues/106) open**. A suitable next movement is to inspect a wider original-authority version window and look for a genuinely differing version-specific source field, admitting only versions with exact page evidence and their own owner-labelled posted days. Never infer missing revisions from equal endpoints or promote conditional calendar-day results to authenticated history.

WORLD's original `game-w13-multiworld-v1` two-room specification remains untouched and is not implied to have completed its independent BUILD/WITNESS contract. Research overlays run separately against the owner-restored original twelve-job NIH/W13 game.
