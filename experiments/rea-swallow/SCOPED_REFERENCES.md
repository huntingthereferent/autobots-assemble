# Movement 5 — real REA scoped-reference experiment

This extends Movement 4's experimentally validated real REA source. The existing ProcessWorkstation copies and branches that source edition again; the MIT upstream repository is pinned at f0b9ef34c404c1c65f8167502db972b0bd708403. Native REA babel-ast-v3 remains unchanged. A new, separate scoped fingerprint resolves references in nested closures and lexical blocks, explicitly returning null for unsupported syntax. All 16 nested argument-selection patterns have identical v3 fingerprints; the new experiment tests distinguishing all 16 while preserving a consistent renaming for each. It also checks shadowing and closure counterexamples, upstream native fingerprint/matching tests and strict TypeScript typecheck. This is not complete arbitrary JavaScript scope analysis and is not wired into upstream version matching.
