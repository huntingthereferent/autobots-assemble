# education_workspace_v1

**Layer:** education workspace  
**Status:** approved, academically informed

## Core

The workspace starts from the learner's current evidenced relation. Academic systems contribute orientation, not learner truth.

## Academic witnesses swallowed

- Canvas: course identity, agenda/to-do, recent activity, upcoming work, feedback.
- Moodle: course overview, activity dates, completion/submission state, simplified scan hierarchy.
- Blackboard Ultra: persistent courses, calendar, activity stream, messages/feedback orientation.
- edX: current courses with an obvious direct continuation action.
- Khan Academy: deeper skill/progress views useful to operators, but progress metrics remain subordinate to actual evidence.

## Preserve

- learner first;
- stable subject/course identity;
- one obvious current/resumable movement;
- today/upcoming near current work;
- recent returned evidence/feedback near the movement it changes;
- current evidenced relation before obligations;
- learning map and standards deeper than the default action layer;
- schedule as time/resource structure, not learner path;
- restrained adult-facing academic density.

## Translate

Default UI should prefer ordinary academic language:

```text
current relation     → In front now / Learning now
reground             → Update from what happened
curriculum obligation→ Learning map / Required knowledge
artifact             → Work / Material / Practice
returned evidence    → Recent work / Feedback / What changed
```

Precise kernel language remains available in deeper/operator views.

## Avoid

No gradebook-first LMS, institutional bureaucracy for its own sake, mastery bars as learner truth, streaks, badges, percentage-progress substitution for evidence, childish decoration, generic AI dashboards, or schedule/course-sequence-as-path.

## Academic hierarchy

```text
learner
→ subject / course
→ in front now
→ Continue
→ today / upcoming
→ recent feedback / evidence
→ learning map
→ obligations / standards
→ artifacts
→ schedule
```

This hierarchy may look academically familiar while remaining evidence-grounded underneath.
