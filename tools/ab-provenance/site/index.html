01 / Start

A tool you can run

Use a disposable repository checkout with the pinned REA source submodule, Python 3.11 and Node 24. The first adapter covers REA's JavaScript matching and observation workflow.

python -m pip install ./tools/ab-provenance
git submodule update --init experiments/rea-swallow/upstream
npm --prefix experiments/rea-swallow/upstream ci

ab source
ab swallow repo --allow-source-edit --repo-root . \
  --out runtime/data/ab-source-tool/first-pass

ab inspect runtime/data/ab-source-tool/first-pass/source-provenance.json
ab render runtime/data/ab-source-tool/first-pass/source-provenance.json \
  -o runtime/data/ab-source-tool/first-pass/source-provenance.html

These commands change only the explicitly selected local REA worktree and require real dependencies. No arbitrary repository execution or automatic publication.

02 / Method

What swallowing means here

  1. Source. Identify the original implementation and exact referent.
  2. Inspect. Determine actual operations, not a rewritten description.
  3. Reground. Preserve and alter source through ProcessWorkstation editions.
  4. Witness. Run native source tests, record contradictions and unknowns.
  5. Continue. Carry only observed supported relations.
  6. Ship. Deliver the corrected A/B tool and its original provenance.

Available commands

ab source
Identify the exact supported source commit and operation scope.
ab swallow repo
Prepare and apply the real source corrections with explicit source-edit permission.
ab inspect / ancestors
Inspect what was actually recorded, including unresolved and invalidated relations.
ab render
Produce an original offline visual provenance inspection.
ab ship
Verify execution receipts and package the original A/B release candidate.
03 / Release

Evidence travels with the package

python -m pip install build
python -m build tools/ab-provenance \
  --outdir runtime/data/ab-source-tool/first-pass/dist
ab ship --repo-root . \
  --evidence runtime/data/ab-source-tool/first-pass \
  --dist runtime/data/ab-source-tool/first-pass/dist \
  --out runtime/data/ab-source-tool/shipped-0.1.0

Shipped artifacts include a wheel, source archive, A/B license, original docs, source receipts, native logs, an evidence manifest, and a provenance view. The release gate rejects missing or changed source evidence and preserves failed experiments.
