# A/B Changelog

## 0.1.0 — release candidate (October 18, 2026)

- Swallow Repo lane: fix or reground original repository relationships.
- Actual pinned REA JavaScript observation, choice, input construction,
  investigation advance, and checkpoint source editions run through
  ProcessWorkstation and verified against native REA Vitest and TypeScript.
- Installable A/B tool: source investigation, ancestry queries and offline
  source-backed visual provenance.
- Evidence-gated A/B release bundle with executable wheel, source archive,
  original documentation, visual evidence and native execution receipts.
- A/B license included in the release and Python distribution. Third-party
  REA source and its separate license do not become the A/B product license.

### Scope

This is a bounded first supported REA source adapter, not absorption of
every REA analyzer and provider, a published GitHub release, or a general
scientific proof. New repositories require separately tested source adapters.

### Original-reference comparison

The source regrounding lane now freezes original REA native results before
modifying source and compares the exact same upstream assertions afterward.
The first original-versus-corrected native reference run matched 22/22
original test assertions on both sides. Full REA CLI/MCP and provider
equivalence remains unimplemented, so the release labels this a
partial native match rather than claiming the same complete product.
