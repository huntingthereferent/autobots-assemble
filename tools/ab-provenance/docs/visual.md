# Visual provenance design

The interface uses the existing design/visual-provenance specialization. Its original research graphic is registered as ab_provenance_graph_v1 and bound to this package.

REA (morluto/rea) is actual pinned upstream source that A/B transforms, tests and uses for native source evidence. It is NOT a visual-design template. Its MIT license is preserved; no REA branding or visual assets are used in the original A/B research surface.

The graph distinguishes referents, native handoffs, recorded events, unresolved nodes and cited evidence references. Dashed relationship lines mark contested or unresolved movement. Clicking nodes or relations shows their original source IDs, evidence_refs, survived/invalidated information, boundaries, transformation and timestamps. Search and scope filters run entirely in the local page; no tracking or external network requests.

The graph is intentionally a restrained research figure rather than decorative AI dashboard cards. It cannot assert that the source labels it renders are true.
