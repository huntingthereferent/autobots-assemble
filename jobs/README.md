# Jobs

Each folder is one stable historical work record.

Naming:
`JOB-###_short-slug/`

Each job contains:
- `JOB.md` — human-readable record
- `job.json` — machine-readable record
- actual implementation/deliverable files
- tests/evidence when available

The 📍 preferred referent inside `JOB.md` is the anchor ChatGPT should recover first when reopening that job.
