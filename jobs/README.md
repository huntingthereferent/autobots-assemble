# Jobs

`jobs/` holds **current retained external work opportunities**, not permanent capability history.

Naming:
`JOB-###_short-slug/`

A retained job may contain:
- `JOB.md` — human-readable external-work record
- `job.json` — machine-readable state
- implementation/deliverable files when they are still part of the active external referent
- tests/evidence when uniquely tied to that opportunity

## Retention

Do not keep an old job merely because it once demonstrated a capability.

When the opportunity is no longer active and the capability can be reproduced more directly by the current system, PURGE the job wrapper unless it preserves a unique external outcome such as submission, acceptance, payment, client feedback, external review, or expensive/non-reproducible evidence.

Reusable capability evidence belongs in `foundation/` or the current canonical project, not in stale job history.

The 📍 preferred referent inside `JOB.md` remains the recovery anchor for jobs that are retained.
