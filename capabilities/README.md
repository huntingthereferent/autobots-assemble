# Capabilities

Capabilities are broad problem-spaces in which repeated evidence shows that the same underlying movement can survive unlike concrete tasks.

They are **not résumé categories** and they do not partition reality into sealed disciplines.

A capability record answers:

> If a new problem arrives in this space, what parts of the complete dependency stack can already be traversed, what witnesses support that, and where are the current walls?
