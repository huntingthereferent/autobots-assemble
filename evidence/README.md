# Evidence Layer

This layer preserves historical inputs, tests, artifacts, snapshots, and manifests.

Evidence may support a current movement, but it does not become the current referent merely because it is older, larger, or more detailed.

## v0.17 archive

\`archive/v0.17-summary.json\` records the packaged archive identity, counts, and SHA-256 hash. The full v0.17 ZIP remains the frozen historical evidence bundle while source and protocols are migrated into GitHub.

Large binaries can remain outside ordinary Git when the available write path requires it, but they must remain represented by stable hashes and provenance.
